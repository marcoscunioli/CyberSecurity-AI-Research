# CyberSecurity-AI-Research
POCs de seguridad en modelos de IA y mitigación de riesgos bancarios
## 📂 Estructura de la Investigación

1. **[prompt_injection_guardrails.py](./prompt_injection_guardrails.py)**: Implementación de lógica de filtrado de entrada para mitigar inyecciones directas.
2. **[pii_data_leak_prevention.py](./pii_data_leak_prevention.py)**: Módulo de DLP (Data Loss Prevention) para evitar que el modelo filtre datos sensibles en la salida.
3. **[adversarial_test_cases.json](./adversarial_test_cases.json)**: Diccionario de TTPs (Tactics, Techniques and Procedures) utilizados para pruebas de Red Teaming en LLMs.
